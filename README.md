# VideoTube — YouTube-style Frontend UI

A responsive video-platform interface inspired by YouTube's layout, built with React, Vite, and Tailwind CSS. Frontend only — all data is mock data, all assets are original.

## Features

- Responsive video grid (1 / 2 / 3 / 4 columns by screen size)
- Live search that filters by title and channel as you type
- Category filter chips (All, Coding, Music, Gaming, Cooking, Travel)
- Collapsible sidebar: icon rail on desktop, slide-in drawer with overlay on mobile
- Sticky header with search and category chips
- Hover play overlay and duration badges on video cards
- Empty state for no search results

## Tech Stack

- React.js (components, state, derived filtering)
- Tailwind CSS v4 (via @tailwindcss/vite)
- Vite

## Getting Started

```bash
npm install
npm run dev
```

## Notes

All video titles, channels, thumbnails (CSS gradients + emoji), and icons are original placeholders — no YouTube assets or real data are used.
